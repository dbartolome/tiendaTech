# AGENTS

Guía rápida para cualquier persona o agente que trabaje en este repositorio.

## Objetivo

Mantener y mejorar la web de DiegoTech sin romper su funcionamiento actual. mejorado
## Reglas de trabajo

- Priorizar cambios pequeños y fáciles de revisar.
- No eliminar archivos existentes sin confirmar necesidad.
- Mantener nombres de archivos y rutas estables (`index.html`, `styles.css`, `app.js`).
- Evitar dependencias innecesarias en frontend (se usa JavaScript vanilla).
- Probar visualmente en navegador después de cada cambio relevante.

## Ejecución

- Comando local: `npm run local`
- URL esperada: `http://127.0.0.1:3000`

## Checklist antes de cerrar cambios

- La página carga sin errores en consola.
- Las imágenes de `assets/` se muestran correctamente.
- No se rompió el layout en mobile y desktop.
