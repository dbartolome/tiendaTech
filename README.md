# Webdemo - DiegoTech

Proyecto web de una tienda tecnológica llamado **DiegoTech**.

## Descripción

Aplicación frontend estática construida con HTML, CSS y JavaScript vanilla.
Incluye un servidor local en Node.js para ejecutar el proyecto en desarrollo.

## Estructura principal

- `index.html`: estructura principal de la web.
- `styles.css`: estilos globales.
- `app.js`: lógica de la interfaz.
- `server.js`: servidor HTTP local para servir archivos estáticos.
- `assets/`: imágenes del proyecto.

## Ejecución local

1. Instalar dependencias (si aplica):
   - `npm install`
2. Iniciar servidor:
   - `npm run local`
3. Abrir en navegador:
   - `http://127.0.0.1:3000`
