# Tecnologías del Proyecto

Este proyecto usa un stack simple orientado a frontend estático.

## Frontend

- HTML5
- CSS3
- JavaScript (Vanilla, sin framework)

## Backend local (desarrollo)

- Node.js
- Módulos nativos de Node:
  - `http`
  - `fs`
  - `path`

## Gestión del proyecto

- `npm` para scripts
- Script disponible:
  - `npm run local` (levanta `server.js`)
